# PYNQ-Z2 Hardware Overlay Directory

This folder holds the compiled FPGA bitstream and metadata files required by the PYNQ framework:

1. **`lane_accel.bit`**: The compiled binary FPGA bitstream generated by Vivado synthesis and implementation.
2. **`lane_accel.hwh`**: The Hardware Handoff XML/JSON metadata exported by Vivado containing the IP block diagram, clock frequencies, and AXI-Lite memory addresses (`0x43C00000`).

---

## How to Export from Vivado:
After running `source create_pynq_block_design.tcl` and `launch_runs impl_1 -to_step write_bitstream` in Vivado:
1. Copy `pynq_lane_detection_bd.runs/impl_1/lane_accel_bd_wrapper.bit` to this directory as:
   `pynq/overlays/lane_accel.bit`
2. Copy `pynq_lane_detection_bd.gen/sources_1/bd/lane_accel_bd/hw_handoff/lane_accel_bd.hwh` to this directory as:
   `pynq/overlays/lane_accel.hwh`

Both files **MUST** share the identical basename (`lane_accel`) so that `pynq.Overlay("lane_accel.bit")` can automatically parse the register address map.
